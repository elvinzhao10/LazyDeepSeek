# LazyDeepSeek

[![Current release v1.4.1](https://img.shields.io/badge/release-1.4.1-0d9488)](https://github.com/elvinzhao10/LazyDeepSeek/releases/latest)

**Plan, build, and verify in DeepSeek Harness.**

Bring native roles, shared settings, and evidence-based workflows to DeepSeek Harness.

- Editable plans and persistent project decisions.
- Focused execution with verification and evidence.
- Checkpoints and handoffs for ongoing work.
- A local dashboard for plans, progress, and package health.

## Get started

Use the [LazyDeepSeek installation guide](https://github.com/elvinzhao10/LazyDeepSeek/blob/main/docs/03-install-and-host-verification.md) for your app. Confirm the integration in a fresh session before starting project work.

## Telemetry and privacy

Harness owns telemetry and session-log upload settings; review its [privacy controls](https://github.com/elvinzhao10/LazyDeepSeek/blob/main/docs/reference/host-routes.md#telemetry-and-privacy). `DSH_TELEMETRY_MODE=DISABLED` is a host opt-out, not a setting this plugin changes.

Package-only checks perform no network I/O. Explicit onboarding, docs requests, and optional tooling may use the network as documented.
